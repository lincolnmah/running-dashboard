# Running dashboard

A personal dashboard combining **Stryd** (running power) and **Garmin Connect** (activities, sleep, resting heart rate, Body Battery, stress) data.

**Open it:** download or clone this repo and open `site/index.html` in a browser. It is a single self-contained page; no server or internet connection needed.

## What's in it

- **Training load:** weekly running distance, weekly hours by sport (running, indoor rowing, strength), weekly Stryd RSS
- **Fitness:** Critical Power history, running efficiency (watts per heartbeat)
- **Recovery:** resting heart rate, sleep, Body Battery peak, all-day stress (7-day averages), with marathon days marked
- **Marathons:** every marathon in the Stryd history with power, %CP and heart rate
- **Chicago 2026, lap by lap:** power and ground contact time per lap, walking breakdown, race-week context
- **Shoes:** lifetime distance per pair

Every chart has a **Table** button showing the underlying numbers, a date-range filter (3 months to all-time), hover tooltips and a dark mode.

## Data coverage

| Source | From | Contents |
|---|---|---|
| Stryd | Dec 2024 | 658 runs (power, RSS, lower-body stress, HR), CP history, shoes, races, Chicago 2026 laps |
| Garmin | Nov 2022 | 2,348 activities, 1,450 days of daily health data, 1,430 nights of sleep |

The Forerunner 245 Music doesn't record overnight HRV, so HRV isn't included.

## Layout

```
site/index.html        the dashboard
site/data.js           all data, generated by scripts/build_data.py
data/stryd/*.csv       Stryd exports (pulled via the Stryd MCP connector)
data/garmin/*.csv      Garmin exports (compact versions of the Personal API export)
scripts/garmin_export.py      pulls Garmin data with your Personal API key
scripts/run_garmin_export.bat double-click runner for Windows
scripts/build_data.py         rebuilds site/data.js from the CSVs
```

## Updating

- **Garmin:** run `scripts/garmin_export.py --start 2015-01-01` with your Personal API key in `connect-personal-api-key.txt` next to it (that file is git-ignored; never commit it), then ask Claude to refresh the compact CSVs.
- **Stryd:** Stryd data comes through Claude's Stryd connector, so ask Claude to refresh it.
- Then run `python scripts/build_data.py` and commit.

This repo is private because it contains personal health data. If you make it public, everything above becomes visible to anyone.
